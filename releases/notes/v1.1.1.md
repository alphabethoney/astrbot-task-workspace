## v1.1.1

本版本发布脱敏后的 Linux／Windows 双任务窗口源码与可移植安装器。

- 延续 v1.1.0 的窗口执行归属、工具校验、本机进程管理、远端执行和进度标记。
- 清除部署专用路径和聊天标识示例；排除运行配置、数据库、日志、备份与字节码。
- 安装器要求显式指定部署根目录和 Python site-packages，保留已配置的本机工作目录与并发限制。
- 添加版本记录、隐私扫描、源码文件清单、可重复构建压缩包和 SHA-256 校验文件。
- 收录 CID 会话管理、咨询窗口、上下文缓存及 Kakobot 设计借鉴方案；这些是后续规划，`/chat list` 等功能尚未实现。

### 安装边界

完整发布源码位于 `releases/v1.1.1/`。这是配套核心与插件的升级包，不是可直接导入的普通 AstrBot 插件 ZIP。已验证基础为 AstrBot 4.27.5 的特定补丁基线，安装器会拒绝不匹配的文件；版本号相同不代表兼容。

三个插件版本均为 v1.1.1。Windows runner 和 LivingMemory 隔离集成需另外配置；仓库 `legacy/` 保留参考实现。本机执行使用服务账户权限，不提供操作系统沙箱。普通聊天保留现有行为。

### 验证

- 28 项隔离测试通过，使用模拟模型／SSH及临时数据库，包含本机进程归属和取消验证。
- 109 个发布文件隐私规则扫描通过，文件清单与压缩包内容校验通过。
- 重复构建的压缩包哈希一致，归档不包含构建机用户名或属主信息。
- 真实 QQ、模型工具调用和 Windows runner 仍需在目标部署中验收。

请下载 `astrbot-dual-windows-1.1.1.tar.gz` 及对应 `.sha256`，先检查 README、隐私说明、第三方声明与基线校验，再在维护窗口升级。发布本版本不会自动升级已有服务。
